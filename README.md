# TypeScript Practice

This repository contains TypeScript practice problems and notes. It
covers basic TypeScript concepts with examples and solutions.

## Project Structure

``` text
.
├── README.md
├── solutions.ts
├── tsconfig.json
├── type-narrowing.md
└── type-vs-interface.md
```

## Files

-   **`solutions.ts`** --- TypeScript problem solutions and code
    examples.
-   **`tsconfig.json`** --- TypeScript compiler configuration.
-   **`type-narrowing.md`** --- Notes and examples about type narrowing.
-   **`type-vs-interface.md`** --- Notes explaining the difference
    between `type` and `interface`.

## Conclusion

The goal of this repository is to practice TypeScript fundamentals and
improve problem-solving skills through simple coding examples.
